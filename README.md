# PDF Local — Eliminar páginas de un PDF


[Open the free PDF tool / Abrir la herramienta PDF](https://eliminarpaginas.com/)


PDF Local is a Spanish-language web tool for removing pages from a PDF directly in your browser. PDF processing happens on your device: the document is not uploaded to a server.


This repository introduces the live website. It does **not** contain the application source code and is not an open-source release of the application.


## What you can do


- Open a PDF and review page thumbnails.
- Enlarge a page in the preview before deciding whether to remove it.
- Select individual pages or ranges, invert a selection, and undo the last selection change.
- Download a new PDF without the selected pages; the original file is not overwritten.
- Use the tool without an account or payment.


## How to use it


1. Go to [eliminarpaginas.com](https://eliminarpaginas.com/).
2. Select a PDF from your device.
3. Mark the pages you want to remove, or enter a range such as `2, 5-8`.
4. Keep at least one page, then create and download the new PDF.


The interface is in Spanish and supports phone and desktop layouts.


## Privacy and practical limits


PDF bytes and page content are processed locally. Visiting the website still downloads page resources. Google Analytics is separate from PDF processing: prior consent is required in the EEA, UK, Switzerland and when the country is unknown; it defaults on in other recognized countries. You can reject analytics everywhere through the footer privacy preferences, and a saved rejection takes priority.


Large documents depend on your browser available memory. Password-protected/encrypted PDFs are not supported in this version. Automatic blank-page detection and adding pages are not currently available. Modifying a PDF can invalidate digital signatures; always keep the original and check the downloaded result.


## En español


PDF Local permite **eliminar páginas de un PDF** sin subir el archivo a un servidor. Revisa las miniaturas, abre una vista previa, selecciona las páginas que no necesitas y descarga una copia nueva. Es gratis y no requiere registro.


La herramienta actual no desbloquea PDF protegidos con contraseña, no detecta automáticamente las páginas en blanco y no permite agregar páginas.
